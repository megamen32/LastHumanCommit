# Rethink a stalled route

Reconsider the approach when attempts keep failing, evidence contradicts the assumed path, the user reports the same unresolved problem, or process grows without a useful result.

Read what was tried and what it established. Choose a concrete repair, a different approach, a better-sized assignment or a model with the missing capability. Ask an Adviser for a genuinely unresolved choice. Preserve the accepted goal when simplifying the work.

Explain the changed route in the existing task note and continue. A longer estimate alone does not repair the cause. A checkpoint or wait timeout is a prompt to inspect the Worker, not a reason to kill a healthy job.

Raise a real user decision with the evidence and a recommendation, then continue work independent of the answer.
