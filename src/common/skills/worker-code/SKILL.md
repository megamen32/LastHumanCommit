# Implement a change

Read the assignment, existing code and relevant project guidance. Trace the real consumer before editing an adjacent adapter or fixture. Use a current code-map entry when it saves a repeated search; confirm the location in source.

Reuse the existing mechanism and build the simplest complete change for the assigned result. Follow the project's types, error handling and test conventions. Add only the abstraction, compatibility or documentation this change needs.

Run the nearest useful check early. For a defect use `worker-bugfix`; for installation or service access use the existing test-access and delivery instructions. Fix failures on the requested path and record unrelated discoveries separately.

Raise a question to the Lead when its wider context changes behavior, scope or ownership. Otherwise resolve ordinary implementation choices and continue. At handoff, report what works, how it was checked, and the commit or artifact that carries it. Update a reusable code-map entry when the change moved a durable path.
