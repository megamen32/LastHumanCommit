# Outcome records

For ordinary engineering, describe the intended consumer action and the result it should produce. A focused canary/readback can establish a bounded change. Use independent review or testing for a requested release assessment or a consequential uncertainty.

The outcome ledger is optional. Its existing commands can retain a scenario, observations and scope when that helps recovery or a selected workflow. A missing receipt or record is not a separate delivery failure.

Keep the result of source checks distinct from an installed-client result. Check the target state before repeating an external mutation with an uncertain outcome, while continuing independent work.
