# LHC skills

Edit the source in this directory. Root skills/ and the installed plugin copies are generated. Load the skill relevant to the current work.

| Skill | Use |
| --- | --- |
| [architecture-design](architecture-design/SKILL.md) | Design a complete solution when an uncertain boundary or assumption would make implementation expensive to redo. |
| [bugfix-tdd](bugfix-tdd/SKILL.md) | Compatibility entry for assignments that name bugfix-tdd; use worker-bugfix for the current defect workflow. |
| [business-delivery](business-delivery/SKILL.md) | Carry an implemented change through the integration, installation and real use required by the task. |
| [challenge-decision](challenge-decision/SKILL.md) | Get an independent challenge when an assumption or proposed route could materially change the outcome. |
| [council](council/SKILL.md) | Ask several suitable models to compare approaches for a requested council or a consequential unresolved decision. |
| [feature-implementation](feature-implementation/SKILL.md) | Compatibility entry for older feature assignments; use worker-code for the current implementation workflow. |
| [focus-groups](focus-groups/SKILL.md) | Use fresh goal-driven testers to find usability problems across the product's relevant audiences and devices. |
| [improve-workflow](improve-workflow/SKILL.md) | Improve an instruction, skill or tool after a recurring problem, useful discovery or explicit user correction. |
| [last-human-commit](last-human-commit/SKILL.md) | Handle an authorized engineering request from the user's intent through a usable result. Use a plan for larger or parallel work, and answer plan/status requests from the session's saved plan. |
| [lhc-rollout](lhc-rollout/SKILL.md) | Recover an explicitly selected legacy LHC Fleet installation using its existing preview, apply and verify commands. |
| [lhc-update-agents](lhc-update-agents/SKILL.md) | Edit canonical LHC sources, rebuild the plugin package and update the selected native harness installations. |
| [maintainer-review](maintainer-review/SKILL.md) | Review a contribution against the target project's rules and conventions when its policy or integration risk warrants it. |
| [mini-improvement-loop](mini-improvement-loop/SKILL.md) | Finish a concrete list of defects from a review, audit or incident with focused repairs and affected-scenario checks. |
| [model-availability](model-availability/SKILL.md) | Read the existing model catalog and quota telemetry before allocating work that depends on them. |
| [model-routing](model-routing/SKILL.md) | Choose a suitable available model and native execution route for the actual assignment. |
| [plan](plan/SKILL.md) | Plan larger or parallel work, keep its current state, and answer requests for the session's overall plan. |
| [plan-artifacts](plan-artifacts/SKILL.md) | Read the commands and file formats for saved LHC plans, their generated views and publication. |
| [real-use-testing](real-use-testing/SKILL.md) | Verify the requested behavior through the actual installed app, browser, device, API or CLI. |
| [release](release/SKILL.md) | Integrate, publish or deploy an authorized change using the project's existing release route. |
| [user-testing](user-testing/SKILL.md) | Try a realistic user goal on the installed product and report observed behavior and candid usability feedback. |
| [worker-bugfix](worker-bugfix/SKILL.md) | Reproduce and fix an assigned behavior failure, then verify the same scenario and protect it against regression. |
| [worker-code](worker-code/SKILL.md) | Implement a coherent assigned change on the real consumer path and check the behavior it is meant to provide. |
| [worker-research](worker-research/SKILL.md) | Find the production path, relevant evidence and next practical change for a repository investigation. |

## Paths

Use ../<skill>/ for a sibling skill. <tools> means common/tools/ in the installed package and common/tools/ in source. AGENTS.md and common/protocols/ are relative to the active package root.
