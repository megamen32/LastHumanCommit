Поля: начало — `plan.started_at`, иначе самое раннее абсолютное `leaf.started_at`, включая отложенную уже начатую работу. `planned_start_at`, mtime и время публикации не являются фактическим началом. Старое ЧЧ:ММ выводится с «дата не записана» без пропорционального маркера. Конец — существующий расчёт оставшихся зависимостей/слотов плюс последнее подтверждённое абсолютное `updated_at` или начало/финиш листа. Внешнее ожидание и неполная оценка явно делают прогноз неизвестным/частичным. Завершение — явный `plan.finished_at` либо финиши всех неотложенных листов; неполные/противоречивые данные не выдают точное завершение.

HTTP текущей страницы обновляет только часы/маркер каждые 15 секунд без серверного запроса и без переноса прогнозного конца. Ревизии используют известный момент снимка; file:// остаётся снимком. Часовой пояс в браузере общий локальный и явно подписан; без JS даты читаемы в UTC. Исходные архивные r001.html не изменяются. Старые источники не мигрируются.

Ограничения: прогноз наследует существующие оценки планировщика; автоматического учёта затраченного времени и нового агрегатора истории нет. Без достоверного абсолютного начала и конца пропорциональная шкала скрыта, текст остаётся видимым. Будущее фактическое начало, дата без часового пояса, конец раньше начала и некорректная дата не создают пропорционального маркера. `updated_at` сравнивается как абсолютный момент вместе с подтверждёнными датами начала/финиша, не по строкам разных часовых поясов; отсутствие такого момента не заменяется `Date.now()`. Старые ЧЧ:ММ остаются исторической записью без даты.
