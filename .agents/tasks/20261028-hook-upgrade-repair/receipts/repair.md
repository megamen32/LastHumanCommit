# Ошибка старого пути после обновления LHC

Скриншот показывает python ENOENT для абсолютного пути native plugin cache 1.6.2/tools/lhc_progress_review.py. Живой cache содержит только1.6.4. Все5progress-hook команд раньше запускали python без проверки файла; shell возвращал2 до запуска кода, хотя сам советник спроектирован необязательным.

Исправление4e2010a/1.6.5: проверка существования файла, стабильный штатный marketplace fallback, отсутствие veto при ошибке советника. Сохранены stdin, args отмены, async и STOP guards. RED11failed→GREEN36focused; общий suite573passed5skipped. Source/package validators и parity прошли.

Различие доставки: исправление опубликовано в main, но новая версия не установлена поверх1.6.4 в этом цикле. Установщик удаляет прежний version-root; это создаёт дополнительный риск для других уже открытых чатов со старыми командами. Ручного изменения кеша/подмены старой версии не делали. Старая команда в Desktop ещё не проверена после исправления; блокер оставлен открытым.

Read-only native schema/docs: поддерживаемая горячая перезагрузка hooks действующего Desktop-чата не установлена. plugin/reconcile явно не является runtime-readiness acknowledgement; config reload отдельного CLI app-server не доказывает перезагрузку Desktop. Документация https://learn.chatgpt.com/docs/plugins требует новой сессии для загрузки установленных пакетов; перезапуск или создание другой сессии не выполнялись.

Точный Airlock rollout не содержит этой ошибки; это не доказывает её отсутствие в Desktop.
