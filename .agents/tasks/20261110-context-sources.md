# Context sources: LHC → GPT Admin

Цель: выбирать актуальные инструкции из MCP Resources, собрать профиль внешнего ИИ и Bootstrap без копирования текстов вручную. Опциональные рабочие пространства и read/write roots — массивы.

Принято: MCP resources/list + resources/read; универсальный descriptor io.gptadmin/context-source с schema_version=1. Ссылка профиля содержит target+uri, не версионный путь. Права на инструменты и пути отдельно от инструкции. Старые профили без context_sources сохраняют совместимость; явный [] не подгружает LHC.

Приёмка: опубликованный LHC возвращает каталог и текущий текст; UI выбирает несколько источников/путей, показывает точный контекст; новый профиль сохраняет массивы и даёт рабочую ссылку; чужой источник и доступ вне roots отклоняются; обновление источника видно без пересборки профиля. Проверить реальную установленную сборку.

Этапы
- [ ] LHC: ресурсы, descriptor, schema, тесты и пакет.
- [ ] GPT Admin: каталог, композиция, профили, Bootstrap, тесты.
- [ ] UI: выбор источников, массив путей, быстрый профиль, предпросмотр.
- [ ] Реальные клиентские проверки, установка, merge и проверка production.

Границы: сохранять чужие рабочие деревья и текущие права; не копировать owner-credentials; не включать ресурсы неизвестного типа автоматически.
