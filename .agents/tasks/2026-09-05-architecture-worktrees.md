## Выбранная политика

- Простой путь остаётся в primary checkout. Для независимых параллельных изменяющих задач Lead может назначать ветки без повторного согласования.
- Один task-slug задаёт branch `lhc/<task-slug>` и path `<primary-project-root>/.worktrees/<task-slug>`. Root проекта определяется по Git, не по текущему harness cwd.
- Lead фиксирует base commit и владельца в задаче. Worker использует выданный путь; harness не создаёт второй checkout или свой каталог.
- Доставка остаётся в main: интеграция проверенных lane-коммитов, итоговая проверка, push; удаление только принадлежащих задаче чистых worktree и достижимых веток после подтверждения remote main.
