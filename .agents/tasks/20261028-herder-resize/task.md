# Регулируемые окна плана и Agent Herder

Принято: компактная внешняя шапка; на компьютере план слева и чат справа, на телефоне план сверху и чат снизу. Граница перетаскивается до полного открытия любого окна. Кнопки возврата к разделению доступны на крайних позициях. Изменение размера не перезагружает сессию.

Исходный дефект подтверждён в опубликованном плане Airlock: внешняя шапка 178 px при viewport 1280×577, iframe перекрывает план.

Исполнение: cost_flow владеет общим UI и узкой регрессионной проверкой; root интегрирует, публикует и проверяет реальный браузер; cost_guidance независимо проверяет состояние native hooks после безопасного обновления.

Проверка: desktop и mobile расположение без перекрытия, изменение размера и крайние положения, возврат к половинам, сохранение сессии iframe, закрытие с восстановлением плана, опубликованный renderer и безопасная установка плагина.

Чужие изменения `.agents/tasks/20261023-human-plans-and-orchestration/*` и удаление `downloaded_files/dashboard.lock` сохраняются и не входят в поставку.
