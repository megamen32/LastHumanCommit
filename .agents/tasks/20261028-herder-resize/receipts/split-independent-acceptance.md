# Независимая проверка разделённого интерфейса

Результат: PASS для родительского интерфейса. Содержимое Agent Herder iframe не принято этой проверкой: в отдельной неавторизованной сессии Chrome показывает broken-page icon; вход или обход SSO не выполнялись. Это ограничение покрытия, не доказательство дефекта авторизованного чата.

URL: https://lhc.bezrabotnyi.com/airlock-internal/plan-20261028-1754-fc098cada54a3462950ac6a0/

AgentBrowser CLI, отдельные session `lhc28split`, namespace `qs28`; во всех действиях `--auto-connect false --headed false --idle-timeout 300000`. Implementation и diffs не читались. Чаты/бизнесоперации не мутировались.

- Desktop 1280×577: обычный клик `Agent Herder` открыл две одновременно видимые области рядом. Разделитель x634..646, значение 50, iframe x646..1280, y44..577. Шапка чата 44px. Screenshot `split-desktop-half.png` сохранён и осмотрен до действий после обнаружения broken iframe.
- Реальный mouse drag разделителя x640→920 при y290 изменил долю плана с50 до72; iframe сжался соответственно.
- Mobile 390×844: после `Разделить поровну` и смены viewport области расположены друг над другом. Разделитель y416..428, значение50; iframe x0..390, y497..844. Разница до iframe включает шапку и отдельную видимую строку о новых обновлениях плана. Screenshot `split-mobile-half.png` осмотрен.
- Mobile реальные клики `Чат`→значение0 (iframe y81..844), `План`→100 (iframe height0), `Разделить поровну`→50. Реальный mouse drag по горизонтальному разделителю y422→600 при x20 изменил долю до71. Половины затем восстановлены.
- Desktop 1280×720: реальные клики `Чат`→0 (iframe width1268), `План`→100, `Разделить поровну`→50. При открытой панели была видна строка «Есть обновления плана. Они применятся после закрытия панели»; поэтому в этом состоянии высота над iframe69px, из них44px основная шапка.

Ошибки автоматизации: две попытки выбрать кнопки через предполагаемый `aria-label` не нашли элемент (у кнопок accessible name есть, этого aria-label нет). Для них отдельный screenshot до следующей команды не был сделан; это пробел протокола, не продуктовый дефект. Дальнейшие реальные клики через точное accessible role/name прошли.

Наблюдение по удобству: компактные `План`, `½`, `Чат` позволяют понять переключение; в половинах мобильный план ограничен верхними422px, прокрутка нужна ожидаемо. Новых подтверждённых дефектов родительской панели не обнаружено. Сам iframe в неавторизованном состоянии не объясняет пользователю причину недоступности, вместо этого Chrome показывает broken-page icon.

Cleanup: собственная session `lhc28split` закрыта успешно; чужая Root rs28 и другие браузеры не затронуты.
