# Контракт интерфейса

- Первый экран: заголовок, полоса ревизий, прогресс, компактные карточки сроков/остатка/мощности. Dashboard по умолчанию.
- Навигация разделов: Дашборд, Цель и результат, План работ, План и факт, Задачи, История. Desktop sidebar; mobile горизонтальная прокрутка, цели касания от 44px. Anchors стабильны, текущий раздел обозначен.
- business_result/business_results сохраняются без переписывания значений: цитируемая декларация «Что будет работать», не сертификат приёмки. current_progress отдельно «Текущий факт».
- Optional plan.acceptance_scenarios: list[str]. Старые планы читаются; отсутствие = «Сценарии проверки ещё не описаны». Коллектор, graph/export, public allowlist и renderer передают поле.
- Revision selectors — отдельные ссылки view-rNNN.html с новым интерфейсом по неизменяемым данным, sidebar переключает разделы. Исторический HTML и JSON не изменяются; оригинальные rNNN.html доступны в истории. Старый просмотр знает все вкладки, но сравнение/прогноз/факты только до выбранной ревизии; poller в нём отсутствует.
- Сохраняются section/hash, поиск, фильтр, scroll, theme при reload. Print показывает все разделы. Таблицы прокручиваются внутри контейнера, 320px без горизонтального overflow страницы.
- Mirror artifact version включает renderer/helper, receipt seq и raw snapshot независимы; restart обновляет current, архивные bytes сохраняются.
- Проверка: адресные source tests, затем Lead устанавливает и проверяет реальный опубликованный URL, desktop/mobile screenshots. Эта сессия не выдаёт source proof за installed acceptance.
