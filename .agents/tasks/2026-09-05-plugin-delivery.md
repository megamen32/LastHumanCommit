# Доставка LHC через Agent Plugins

Started at 2026-09-05T05:54:39+03:00 (clock.curr_time).
Результат: один самодостаточный Agent Plugin, штатное обновление на 100/44/88/Mac M1 и выключенный старый путь обычного rollout.
Canary: каждый установленный loader обнаруживает актуальный пакет и читает правила из него; исходники, установка и новая сессия проверяются отдельно.
Минимальный срез: исправить операторские инструкции, включить канон в пакет, использовать существующие plugin managers; убрать активные старые дубликаты после проверки новой загрузки.
Не строим: новый менеджер пакетов, новую службу синхронизации, форки harness, автоматические рестарты чужих активных сессий.

Состояние: два read-only исследования загрузчиков (44/88 и Mac) параллельно с изменением канона Worker и упаковкой Lead. Legacy preview не применялся. Пользователь явно выбрал Agent Plugin вместо Fleet-copy и разрешил постоянную запись предпочтения.
Оценка после изменения маршрута: исследования 3–5, канон 3–5 и упаковка 5–10 параллельно; установка 4–8, приёмка 3–6 последовательно: 12–24 минуты, трудозатраты 18–34. Разброс зависит от уже установленных версий loaders и наличия их plugin commands; активное время непрерывно не контролируется. Это новый маршрут после явно изменённого пользователем способа доставки, не задним числом изменённая прежняя оценка.
