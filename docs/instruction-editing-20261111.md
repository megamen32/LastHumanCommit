# Instruction editing, November 2026

## Purpose

Rewrite the active LHC roles, instructions, skills, task templates and injected reminders for readable, proportionate work. Boss keeps detailed examples of drift as an open-ended list and continues to respond in free prose.

Used their advice on concrete language, fewer repeated caveats, useful detail, proportional research and small coherent changes. Did not import absolute bans on grammar, scoring rubrics, repeated rewriting loops or an entire stack of editor prompts into the runtime.

## Deliberate workflow changes

- Research ends when the next decision is supported, not after a minimum ten-minute wait.
- Criticism addresses material weaknesses; it need not repeat until no possible objection remains.
- A small direct fix does not need an artificial team, council or mandatory second tester.
- Task-blocking defects and regressions are fixed; unrelated discoveries remain visible as separate work.
- Test at the layer where the defect occurs, including integration when appropriate.
- Keep reusable QA identities; clean transient fixture data according to its purpose.
- Reminders prompt a useful decision, not another mandatory report or ritual.
- Preserve native permissions, user stops, secret handling, shared-write coordination, exact dispatch identities and API contracts. These have concrete effects and are not removed by a prose edit.

## Scope

The root guide and product intent, all ten roles, four profiles, twenty-three skills, eighteen protocols, five harness adapters and their child templates, common command/task templates, and the active intake/heartbeat reminder text were inspected. Technical reference sections retain useful schemas, command examples, bounds and compatibility behavior. Historical verification reports remain historical.

Generated package copies follow the canonical sources through the existing publishers. This is an instruction change, not evidence that every installed runtime has reloaded it or that models will always follow it.

## Direct user corrections during editing

Boss audits remain mandatory roughly every 30 active minutes. They are separate from optional workflow telemetry and are not removed as process cleanup. The role now calls out that exact self-authorized scope reduction.

Before fullcycle work the Lead must show exactly three short alternative plan summaries and wait for the user to choose. Only then does it fully decompose the chosen route, allocate parallel work and execute. Limited read-only investigation may prepare the summaries; the Lead recommendation is not the selection.
