A metadata-only receipt error with a known reviewed commit is repaired once from Git/CI and proceeds to the permitted delivery/user canary. Material code/environment changes still require appropriate review, and unknown coverage is never changed into a fabricated PASS.

The native V2 adapter calls the canonical Python lhc_entry, not a stale TypeScript text clone. Prompt and context hooks, actual tool/terminal/permission/compaction events share the existing guarded native per-session state. Compaction restores the original and latest user instructions, not an unrelated nearest task file. Hook failure remains non-fatal; stopped sessions are not revived. The OpenCode lifecycle does not provide the same blocking Stop continuation mechanism as Codex: overdue reviews are injected on supported model/context boundaries and stay due until acknowledged, but an idle completion by itself cannot force another model turn.
