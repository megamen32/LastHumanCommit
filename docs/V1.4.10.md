independent Codex/Luna testers for mobile and desktop, without a coordinator reminder.

browser command at the start of the shell string and required the first public URL.

explicitly assigned tunnel address were genuine work but not recognized.

browser command batches and actual get-url navigation evidence, and accepts surface
addresses explicitly present in the already task-correlated fresh native assignment.
Quoted browser text printed by printf/echo is still not browser execution. Original
native-source identity, actual interactions, changed state, complete raw feedback,
distinct fresh users and honest untested/blocked outcomes are retained. This is not
a new receipt or semantic grader; Lead still interprets actual user-goal coverage.
